# Example SEO audit product design

This is a generic architecture example, not a private product roadmap or a client case study.

- Offer an initial domain scan and a detailed audit report.
- Track score history and evidence across repeat audits.
- Keep client workspaces isolated and use per-client credentials.
- Make remediation an explicitly authorized step with backups and rollback.
- Set product naming, pricing, distribution, and rollout plans in a private project document.
